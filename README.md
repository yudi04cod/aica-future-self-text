One funny text message your future self sends you — under 200 characters, no setup, just the message as it would arrive.

## The entry

> Future you here. Stop watering the plant — it's plastic. And the password you just changed? You'll forget it by Thursday. I know. I'm you. I forgot it twice already.

## Run it

```sh
python3 main.py
```

Writes the text to `/output/entry.txt` (165 characters, one line, byte-identical on every run).
